Demo Mode

Turns on a limited-spin test mode - "DEMO MODE" shows on the game screen while it's active, and results aren't added to your Win History (they're saved to their own separate printable file on the machine instead). It automatically switches itself back off once the spin count below runs out, so it can't be left on by accident - tick it again any time you want another batch of test spins.
